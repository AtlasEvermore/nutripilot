# Checklist de lancement France

## Produit
- [ ] Nom de marque final + domaine.
- [ ] OPENAI_API_KEY / OPENAI_MODEL testés avec 30+ photos réelles variées.
- [ ] Test de recalcul des portions.
- [ ] Test de 20 codes-barres français.
- [ ] Test iPhone Safari + Chrome Android + desktop.
- [ ] PWA installée sur au moins 2 appareils.

## Hotmart
- [ ] 3 offres créées en EUR.
- [ ] Prix, périodicité, essai et renouvellement visibles sans ambiguïté.
- [x] Checkout mensuel intégré : offre r3ueswug.
- [x] Checkout 3 mois intégré : offre xb98vzl6.
- [x] Checkout annuel intégré : offre gatqnh54.
- [ ] URL de succès Hotmart → `/?paid=1#access`.
- [ ] Webhook Hotmart → `/api/hotmart/webhook`.
- [ ] Signature webhook testée.
- [ ] Eventos exatos de aprovação/revogação configurados.
- [ ] Compra real em EUR concluída.
- [ ] Reembolso/cancelamento testado.
- [ ] Moeda e valor líquido de recebimento conferidos.

## Jurídico / confiança
- [ ] Razão social/nome, endereço e identificador da empresa completos.
- [ ] CGV/CGU validadas para serviço digital B2C França.
- [ ] Política de privacidade/RGPD final.
- [ ] Processo de exclusão/exportação de dados documentado.
- [ ] TVA/VAT e papel da Hotmart confirmados por escrito.
- [ ] Política de reembolso/retração compatível com a entrega digital real.
- [ ] Consentimento de cookies/analytics quando aplicável.

## Tracking
- [ ] Meta Pixel no site.
- [ ] UTM preservada até checkout.
- [ ] Eventos StartQuiz / CompleteQuiz / BeginCheckout / PremiumActivated testados.
- [ ] Página de obrigado e ativação testadas.

## Criativos
- [ ] Anúncio promete apenas o que o app realmente entrega.
- [ ] Sem afirmação de calorias « 100% exatas » por foto.
- [ ] Demonstração real do fluxo photo → correction → log → next meal.
