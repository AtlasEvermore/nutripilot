# Constellation and NEXUS candidate — 26/10/2026

The existing NutriPilot app receives a shared material/control refinement across its workspaces: ice/cyan primary actions, lime commercial and meal actions, module colors, precise focus, responsive headers, composed cards, coordinated transitions and reduced-motion support. Existing modules, prices, entitlements and records remain in place.

Atlas replaces the Apps hero's passive orbit with an interactive map of all nine real modules. Touch and ordinary keyboard buttons select a destination; arrows/Home/End support traversal, including RTL. Selection updates the module description and a separate next action without changing profile, route or access. The original searchable/filterable module library remains below.

NEXUS is an offline task-ordering engine on the authenticated Today summary. Its pure input/output rules use meal count, logged water, training schedule/completion and entered sleep times. Four selectable signals expose their source and explain the next navigation action. A missing sleep/meal record is displayed as missing. There is no clinical inference, invented wellness score, remote model call or implicit write. Adding a meal, viewing the water tracker, opening the training plan and opening the sleep diary use existing flows. Actual record changes refresh the panel on the next render. Module visibility follows the existing entitlements.

When analysis is paused, the visitor scanner example no longer shows a photo-analysis result as an available capability; barcode/manual access remains.

All new interface text is translated in the existing fourteen-language system. New animation is disabled for reduced motion and suspended in background tabs; the existing modest-device behavior is retained. No new image generation, framework, external asset request or paid provider was introduced. Version and native sources are unchanged.

Validation will be recorded after the candidate passes CI and visual inspection. Browser screenshots use synthetic test accounts, simulated identity responses and fictitious records. They are not proof of a real subscription purchase or a production deployment. Publication remains controlled by AGENTS.md and the unchanged release gate.
